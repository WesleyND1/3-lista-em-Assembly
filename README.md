# 3 Lista de Exercícios em MIPS Assembly

Este repositório contém as soluções de exercícios práticos desenvolvidos em **MIPS Assembly**, utilizando o emulador **MARS** (MIPS Assembler and Runtime Simulator).

# Conteúdo dos Exercícios

1. **Conversor de Real para Dólar:** Cálculo de conversão financeira simples com divisão e taxas fixas.
2. **Troca de Valores (Swap):** Troca do conteúdo de registradores utilizando registradores auxiliares.
3. **Cálculo de Idade em Meses:** Cálculo a partir do mês e ano de nascimento versus mês e ano atual.
4. **Aumento Salarial (25%):** Aplicação de cálculo percentual em valores inteiros.
5. **Classificação de Raízes (Delta / Equação do 2º Grau):** Verificação das raízes reais de uma equação do segundo grau a partir do $\Delta$ (`bgtz`, `beq`, `blt`).
6. **Comparador e Ordenador (Maior e Menor):** Leitura de dois números com identificação e ordenação no console.
7. **Decomposição Numérica (Centena, Dezena, Unidade):** Leitura com validação de intervalo $[100, 999]$ e extração de dígitos via operações de módulo e divisão (`mflo`, `mfhi`).
8. **Simulador de Parcelamento de Loja:** Validação de intervalo de compras, cálculo de parcelas fixas e identificação de parcela residual.

---

## 💻 Requisitos do Ambiente
* Java Runtime Environment (JRE) instalado.
* MARS Simulator ou SPIM Simulator.
